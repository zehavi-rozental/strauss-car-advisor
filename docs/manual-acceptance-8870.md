# בדיקת קבלה ידנית — שרת הבדיקות 8870

סביבה: `http://localhost:8870/employee` (עובד) ו־`http://localhost:8870/rep` (נציג).
השרת פועל עם Gemini, מייל מדומה (קבצים בתיקיית הנתונים, אף מייל לא נשלח), ובסיס נתוני בדיקות נפרד.
קוד הנציג נמצא רק ב־`backend/.env` (לא ב־Git). נתונים סינתטיים בלבד.

לכל בדיקה: מה לעשות, ומה חייב להופיע. סמנו ✓ או ✗ והוסיפו הערה.
